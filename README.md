# AI-Based Intrusion Detection System (IDS)

## 🚀 Overview
A Flask-based web application that detects network intrusions using Machine Learning.

## 🔧 Features
- Upload CSV network traffic
- Detect anomalies using Isolation Forest
- Classify attack types
- Interactive dashboard

## 🛠️ Tech Stack
- Python, Flask
- Scikit-learn
- Pandas, NumPy
- HTML, CSS, JS

pip install -r requirements.txt
